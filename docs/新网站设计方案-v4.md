# 甜薯剧本杀 · 第四版网站设计方案（ui=4）

> 目标：**另一套网站**，不是同一套网站的另一张皮。
> 依据：51 个 Awwwards 获奖站的逐帧拆解（casebook）+ 官方评审共识。
> 原则：**先做设计，后接功能**。这份文档通过之前，不写一行业务代码。

---

## 零 · 为什么前八套皮肤是失败的

必须先把失败原因钉死，否则第四版会重复犯错。

| 我做的 | 顶级站的做法 |
|---|---|
| 一套骨架 + 八种配色 | 一个想法，执行到底（One idea, executed completely） |
| 卡片等宽排列、左图右文、顶栏导航 | 布局本身是叙事材料，网格会被主动打破 |
| hover 变色、滚动浮现 | 滚动位置驱动**转场**，区块之间是"镜头移动"而非"翻页" |
| 装饰性动效 | 技术匹配主题（technique matches the subject） |
| 横平竖直 | 斜切、重叠、位移、缩放、遮罩 |

评审共识原文：**"获奖作品没有一件是效果集合；全部是一个承诺，贯穿始终。"**
以及：**"技术一旦是随意的，评委读到的就是装饰。"**

**所以第四版的核心命题是：一个承诺。**
不是"我们有很多效果"，而是"这个网站是一件事，从头到尾都是那件事"。

## 一 · 核心概念：**「开本」**

剧本杀的本质不是"浏览商品"，是**翻开一个本、进入另一个人的一生**。
现有网站把这件事做成了"电商列表"，这是根本性的错位。

**第四版的承诺：整个网站是一本被翻开的书。**

- 首屏不是横幅，是**封面**
- 滚动不是下滑，是**翻页**
- 剧本不是卡片，是**书中一页**
- 进入剧本详情不是跳转，是**翻开一本新书**

这一个概念统领全部设计决策 —— 布局、动效、转场、字体、配色，全部服务于"翻书"这一个身体感觉。**这就是那个"一个承诺"。**

---

## 二 · 布局：彻底打破横平竖直

采用四套布局系统，**互相咬合**，而不是全站一套网格。

### 2.1 首屏：**斜切封面**（借鉴 Don't Board Me 的"几何门"）
- 全屏不是矩形分割，而是**一条斜线切开的两块色域**，上块是"封面"，下块是"内页预览"
- 斜线角度随滚动微调（`-14deg → -8deg`），像书被掀开一角
- 标题压在斜线上**跨缝排布**，不居中、不对齐，制造张力

### 2.2 剧本墙：**水平轨道 + 重叠色板**（借鉴 Akaru）
- **垂直滚轮 → 水平移动**。五本剧本并列成一条横轨
- 每本是一个**全高色彩面板**，后一本从 `x:-31vw` 滑出并覆盖前一本
- 每本的色场从 `20% 宽度` 撑开到全屏 —— **每本剧本用自己的颜色占领屏幕**
- 轨道走到尽头后整体**缩到 50% 并归位**，衔接下一区

> 关键：这彻底不是"卡片流"。用户是在**横向浏览一排书脊**。

### 2.3 场次表：**发牌堆叠**（借鉴 Don't Board Me 的 dealt card deck）
- `position:sticky` 的舞台 + `400vh` 的兄弟轨道（**不用 pin，纯 CSS 粘性**）
- 四张场次卡从 `top:100%` 依次"发"到桌面，每张带**轻微倾斜**（`rotate(-3~3deg)`）自然散开
- 卡与卡**故意重叠**，像真的摊在桌上

### 2.4 底部：**滚动绘制的路径脊柱**（借鉴 MindMarket）
- 一条手绘感的细线 SVG 从页头**蜿蜒贯穿到页脚**，`preserveAspectRatio="none"`
- 线的**描边进度跟滚动绑定**（`stroke-dashoffset`），像有人在纸上画线
- 沿线"种"上站点地图的各个入口 —— 导航不再是顶栏列表，而是**沿路径分布的节点**

## 三 · 转场：区块之间是镜头移动，不是翻页

这是"流畅过渡"的具体实现。**每个区块边界都是一个转场。**

| 转场 | 手法 | 来源 |
|---|---|---|
| 封面 → 内页 | **斜切色块擦除**：一块实色从右向左扫过，扫过处新内容揭开 | Lando Norris 的 lime block reveal |
| 内页 → 剧本墙 | **撕裂纸边擦除**：`clipPath` 多边形带噪声边缘推进 | Renaissance Edition 的 torn-paper wipe |
| 剧本墙 → 场次 | **升起圆盘**：一个 `130vw` 的圆从底部升起覆盖全屏，标题沿圆弧排布 | casebook 的 rising disc |
| 场次 → 详情 | **翻页折角**：`transform-origin: bottom left` + `rotate(-15deg)`，纸角掀起 | The Line Studio 的 paper-sheet physics |
| 进入剧本详情 | **整页遮罩揭示**：`clipPath: inset(100% 0 0 0) → inset(0)`，`1.2s power4.inOut` | Akaru 的菜单揭示 |

**统一纪律**：所有转场只动 `clip-path` / `transform` / `opacity`（GPU 友好），
时长 0.6–1.2s，缓动统一用 `power4.inOut` 或 `expo.inOut`。**绝不各动各的。**

## 四 · 特殊动画（真正特殊的那几个）

### 4.1 光标驱动的纸纹压痕（借鉴 Immersive Garden）
- 一个 `128px` ping-pong render target 记录鼠标轨迹，`dissipation 0.953`
- 鼠标划过时，**纸面像被压出凹痕**，凹痕缓慢消退
- 这是"纸"这个概念的身体化表达 —— **技术匹配主题**

### 4.2 滚动速度驱动的拖影（借鉴 Pacôme Pertant / Siena Film）
- 滚动越快，剧本标题**被拉长、模糊、拖影**（`scaleX` + `blur`）
- 停下时恢复清晰 —— 像快速翻书时字迹糊成一片
- 用平滑后的滚动速度做驱动量，`floor` 保证静止时不抖

### 4.3 逐字墨迹填充（借鉴 Opal Tadpole / Oryzo）
- 长段落渲染两遍：底层 `opacity:.1` 幽灵字，上层逐字 `opacity:0→1`
- 进度由滚动位置驱动，**字像被一笔一笔写上去**
- 不用动画库时间轴，**每帧算进度**，滚动到哪写到哪，回滚也能回退

### 4.4 页码滚动器（原创，服务"书"的概念）
- 右侧竖排一个**页码轨**，随滚动走动
- 每一"页"到位时，页码**翻牌式**切换（上下两半错位滑入）
- 这替代了传统的"回到顶部"按钮，同时强化"书"的隐喻

## 五 · 字体与色彩

### 字体（三层，各司其职）
- **封面巨字**：超宽重量级 grotesk，`clamp(96px, 15vw, 190px)`，`line-height .84`，`letter-spacing -.05em`
  —— 只用在上面的"封面"，不滥用
- **内文**：思源宋体 —— 呼应"书"，且中文渲染好
- **数据/编号**：等宽字体，用于页码、场次号、价格

### 色彩（**一套，不换肤**）
不再是"八种配色"，而是**一套有纪律的用色**：
- **纸**：暖白 `#F4F1E8`
- **墨**：近黑 `#14120F`
- **一个强调色**：使用**朱砂红 `#B7231C`**（印章、页码、关键动作）
- **一个辅助色**：**靛青 `#1F3A5F`**（仅在"已满/不可用"等状态出现）

> 纪律：**强调色全站出现次数要能数得过来。** 顶级站通篇只有一个颜色事件。

## 六 · 技术债与约束（必须正视）

| 项 | 决策 | 理由 |
|---|---|---|
| 动画库 | **不引 GSAP**，用原生 `IntersectionObserver` + `rAF` + CSS `animation-timeline` | 现在站点无构建流程，引 CDN 一旦挂掉整站不动 |
| 平滑滚动 | **自实现极简惯性滚动**（已有 `skin-fx.js` 里的实现可复用） | 同上，不引 Lenis CDN |
| WebGL | **不用**，纸纹压痕改用 Canvas 2D + `globalCompositeOperation` | 避免引入 three.js 的体积与性能风险 |
| 无障碍 | 全部动效走 `prefers-reduced-motion` 降级；内容默认可见，动效只做增强 | 拆解库里多处"内容隐藏在揭示后"是明确的扣分项 |
| 性能 | 只动 `transform`/`opacity`/`clip-path`；Canvas 的 `DPR` 上限 2 | 60fps 是底线 |

**已识别的坑（来自拆解库的 Watch out 段）**：
- 行遮罩会**切掉 j/p/q 的降部** —— 中文不受影响，但英文标题要注意留 `padding-bottom`
- 内容若默认 `opacity:0` 等 JS 揭示，**JS 挂了内容就没了** —— 必须默认可见
- 米白/奶油底色是"AI 味"的重灾区 —— 靠朱砂红和布局张力压住

## 八 · 需要你拍板的三个点

1. **「书」这个概念你认不认？** 如果认，我全站都往"翻书"上做；不认，我得换一个统领概念（但我坚持必须有**一个**概念）。

2. **水平滚动你接不接受？** 剧本墙用垂直滚轮驱动水平移动，这是最"非横平竖直"的一块，但少数用户会不习惯。可以做成**桌面端水平、手机端纵向**。

3. **要几个概念？** 我上面列了 4 套布局 + 4 个动画 + 5 个转场。**可以做满，也可以只挑 2–3 个做到极致。**
   顶级评审的原话是"一个想法，执行到底"。我的建议是**做满布局与转场，动画精选 2 个**（纸纹压痕 + 滚动拖影）。
