## 一 · 「AI 味」到底是什么，我怎么降

这不是玄学，是一份可以逐条打勾的清单。我先把清单钉在墙上，再定颜色。

### 1.1 AI 味的五个病灶（来自对 500+ 站的模式扫描 + 官方评审共识）

| 病灶 | 具体表现 | 我上一版有没有踩 |
|---|---|---|
| **默认配色** | 靛蓝→紫渐变、蓝紫撞色、**米白/奶油/beige 底**、`#e8e8e8` 中性灰 | ✅ 踩了（米白底） |
| **默认字体** | Inter / Roboto / 系统 sans 全局通吃、Space Grotesk | ⚠️ 部分（mono 门面） |
| **默认布局** | 居中 hero + 徽章 + 两个按钮 + 三张等宽卡片；**均匀 16px 圆角** | ✅ 踩了（上一版没解决） |
| **默认组件** | 毛玻璃配模糊色块、深色 hero 配紫色渐变、emoji 当产品图、滚动 fade-up | ⚠️ 部分 |
| **默认"高级感"** | 淡方格背景、物背后加径向光晕、字母间距拉开的衬线小型大写 logo | ✅ 踩了（graph-paper tell） |

**核心判据**（这句话是整个方案的基石）：

> **单个元素都不算错。"所有选择都是默认值"才是 slop。**
> 米白底也不是绝对不能用 —— 它只有在**被强饱和色压住**的时候才成立。
> 一旦丢掉强色，米白就只剩"AI 很温柔"，那就是 slop。

### 1.2 我的四条降 AI 味纪律（可验收）

1. **颜色必须"有出处"**：每一个色值都能说出它在现实里是什么（朱砂、靛青、牛皮纸、油墨黑）。**说不出出处 = 删掉。**
2. **强调色出现次数能数得过来**：全站高饱和色是"事件"，不是"背景"。背景永远让位给纸/墨。
3. **禁止清单（硬删）**：靛蓝→紫渐变 ❌ / 淡方格背景 ❌ / 均匀 16px 圆角 ❌ / emoji 当图 ❌ / 统一 fade-up 入场 ❌ / 物背后径向光晕 ❌。
4. **字体必须"选得出来"**：中文站就用中文的字面骨架，不拿英文 sans 当通稿。

## 二 · 五个统领概念（不是一个）

你说得对，不能全是书。我把这个站的内容翻了一遍 —— 它真实有的是这些：

- 剧本（一本书、有封面、有角色卡、有作者、有难度、有场次数）
- 场次（几点开、哪个房间、谁带、几个人、还剩几个位置）
- 拼车（正在凑人、差几个、什么时候发车）
- 玩家评价 / 复盘
- 店里的样子（实拍）
- 通知

**同一批内容，可以被五种完全不同的"世界观"统领。** 每种世界观推出一套**结构不同、动效不同**的版式：

| # | 统领概念 | 现实原型 | 它推出的信息架构 | 首屏是什么 |
|---|---|---|---|---|
| **A** | **开本** | 一本书被翻开 | 封面 → 目录 → 逐页展开 → 合上 | **封面**：只有书名、作者、一句话，别的什么都没有 |
| **B** | **剧幕** | 剧场节目单 / 场次牌 | 幕次表（第几场·几点·哪个厅·还剩几张票）| **节目单**：整屏是"今晚的幕次表"，像影院门口的排片屏 |
| **C** | **卷宗** | 侦探的证据墙 | 线索板：每个剧本是一份档案袋，拉出来是线索卡 | **线索墙**：一堆钉在板上的档案袋 + 红线连成的推理图 |
| **D** | **分镜** | 电影胶片 / 脚本 | 镜头条：横向排列的"镜"，一镜一本 | **胶片条**：一条齿孔胶片铺过去（纵向下滑，镜头逐格推进） |
| **E** | **站牌** | 学校公告栏 / 手写黑板 | 公告墙：贴纸、图钉、便利贴、值日表 | **公告墙**：真的像走廊那面墙，钉满手写纸 |

**关键**：这五套不是"五种配色"，是**五种完全不同的排版骨架**。同一个剧本在 A 里是一页书、在 B 里是一张票、在 C 里是一个档案袋、在 D 里是一格胶片、在 E 里是一张手写便签。

> **技术上怎么并存**：后台「网站版式」下拉里并排列出来，前缀统一叫「三代 · XXX」。
> 五个 key 写成 `4/5/6/7/8`（`3` 已被现有"竖排导轨"占用，不能动）。

## 三 · 每一套「不一样」在哪（这一节是方案的骨头）

上一版最致命的问题是：四套布局**都长在同一个网格上**。这次每一套的**版面几何**就是不同的。

### A · 三代 · 开本（书）

- **几何**：竖排、单栏、**装订线在左**。内容严格贴着一条"书脊"排，右边留白给批注
- **首屏**：一整屏封面，居中书名，底下只有一行小字"翻开"
- **滚动**：`scroll-driven` 的**页面卷曲** —— 页面翻过去时右侧有轻微阴影和弧面（纯 CSS `transform: perspective + rotateY`，不做 3D 引擎）
- **剧本**：一页书。左页是简介、右页是角色卡
- **不同在哪**：**装订线 + 卷曲**这套版面，别的四套都没有

### B · 三代 · 剧幕（剧场节目单）

- **几何**：**横向的时间轴**当骨架 —— 但**不横向滚动**，而是时间轴竖直、每一"幕"是一整屏
- **首屏**：像影院排片屏，黑底白字，"今晚 19:00 / 20:30 / 22:00"三幕高亮
- **核心动效**：**幕布升起** —— 每一幕进入视口时，一块同色幕布向上卷起，露出内容（`clip-path: inset(0 0 100% 0)` → `inset(0)`）
- **场次**：直接就是主角，不用绕一圈
- **不同在哪**：**以"场次"为第一公民**，剧本是场次的附属。A 里剧本是主角，B 里场次是主角

### C · 三代 · 卷宗（证据墙）

- **几何**：**绝对定位的散落拼贴**。档案袋、照片、便签各自带 `rotate(-6deg ~ 6deg)`，随机钉在墙上
- **首屏**：一面软木板，钉着 6-8 个档案袋，红线把它们连起来（红线是 SVG，可 hover 高亮某条线）
- **核心动效**：**拉出档案袋** —— 点击/滚动时，一个档案袋从墙上"拉出来"放大成整屏
- **剧本**：一份卷宗，有编号、有"案件摘要"、有线索卡
- **不同在哪**：**唯一的散落式/杂乱式版面**，其他四套都是有序的

### D · 三代 · 分镜（胶片）

- **几何**：**中轴水平条 + 上下齿孔**。画面在中间，上下各一排齿孔（用 `repeating-linear-gradient` 画）
- **首屏**：一格巨幅画面（最新那个本），上下齿孔提示"可推进"
- **核心动效**：**逐格推进**（**不是横向滚动**）—— 纵向滚动时，画面**像胶片走片一样往下走一格**，`transform: translateY(-100%)` + 上下相邻格淡入
- **不同在哪**：**纵向的"帧"概念**，一屏一帧，绝不横滚

### E · 三代 · 站牌（公告栏）

- **几何**：**手写 + 图钉 + 便利贴**。字体用带手写感的中文（如"方正静蕾"类的开源替代，或系统手写体降级）
- **首屏**：一面公告栏，"今日小黑板"占最大那张，周围钉着通知、拼车、值日表
- **核心动效**：**纸片飘落** —— 滚动时纸片有极轻的 `rotate` + `translateY` 摇摆（`animation-timeline: scroll()`），像墙上被风吹动的纸
- **不同在哪**：**唯一一个"非设计感"的版面** —— 它故意做得像随手贴的，反而最不像 AI

## 五 · 动效：丰富，但每一下都有理由

你的要求是"**表现形式尽可能丰富但流畅，用户用得舒服**"。我拆成两半：**丰富**给视觉，**舒服**给手感。

### 5.1 让用户"舒服"的四条硬规矩（优先于好看）

1. **绝不劫持滚动**。不用 `preventDefault` 改滚动方向，不加速度曲线伪造惯性。**用户滚多少，页面走多少。**
2. **动效只做"揭示"，不做"阻挡"**。任何动效结束后内容必须完全可用。
3. **内容默认可见**。JS 挂了、动画没跑，页面照样能读（拆解库里多个站因为这条被扣分）。
4. **一律走 `prefers-reduced-motion`**。用户开了"减少动态效果"，全部降级为直接显示。

### 5.2 每个概念的核心动效（各一个，做到底）

| 概念 | 那个"一个动效" | 技术 |
|---|---|---|
| A 开本 | **页面卷曲** | `perspective` + `rotateY` + 渐变阴影 |
| B 剧幕 | **幕布升起** | `clip-path: inset()` + `cubic-bezier` |
| C 卷宗 | **红线生长 + 档案袋拉出** | `stroke-dashoffset` + `transform-origin` |
| D 分镜 | **逐格走片** | `translateY(-100%)` + 相邻帧淡入 |
| E 站牌 | **纸片微摆** | `animation-timeline: scroll()` + 微 `rotate` |

### 5.3 全站共用的两个"手感"动效（不喧宾夺主）

- **逐字墨迹填充**（滚动到哪，字写到哪）：长段落底层 `opacity:.1` 幽灵字，上层逐字显现，**进度每帧算，可回退**
- **数字滚字机**：累计开本数从 0 滚到位（`requestAnimationFrame`，不用库）

> **这两个只在 A 和 E 用**，B/C/D 不用 —— 因为要保每套的独立性。

## 六 · 技术方案（沿用上一版的克制作风）

| 项 | 决策 | 理由 |
|---|---|---|
| 动画库 | **不引 GSAP / 不引 Lenis** | 站点无构建流程，CDN 一挂整站崩。全部用原生 `IntersectionObserver` + `rAF` + CSS `animation-timeline` |
| 3D | **不引 three.js** | 页面卷曲用 CSS `perspective` 就够，不上 WebGL |
| 横向滚动 | **彻底删除** | 你的指令 |
| 性能 | 只动 `transform` / `opacity` / `clip-path`，`will-change` 按需开关，`contain: layout paint` | 60fps 底线 |
| 手机端 | **每套都有移动端降级方案**（见下） | 舒服优先 |

**手机端降级**（这个上一版没写清）：
- A 开本：单栏不变，卷曲幅度减半
- B 剧幕：幕布升起改为直接淡入（`clip-path` 在低端机不流畅）
- C 卷宗：散落拼贴改为**两列网格**（避免点击目标重叠）
- D 分镜：齿孔隐藏，逐格保留但加快
- E 站牌：纸片微摆关闭（省电）
