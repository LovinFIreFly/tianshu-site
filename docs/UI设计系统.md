# 🌐 网站UI设计系统学习文档 - 甜薯剧本杀（Python 版）

> 风格来源：参考案例的「深色背景 + 高亮荧光绿 + 强科技感 + 沉浸感」，在它基础上做了适配（橙黄只留给"钱"）。
> 样式表唯一：`tianshu/static/css/style.css`（约 20 KB，14 段：令牌 / 基础 / 布局 / 导航 / 卡片 / 徽章 / 按钮 / 表单 / 表格 / 提示 / 页面零件 / 独立登录界面 / 浅色主题 / 杂项）

## 1. 设计概览与风格

*   **关键词**：暗色 · 荧光绿 · 科技感 · 沉浸 · 细描边
*   **整体印象**：页面是接近纯黑的深底（`#06090d`），上面铺一层很淡的网格，顶部有荧光绿的辉光；主色是**高亮荧光绿 `#00ff9d`**（按钮、选中、链接、核销码都发微光），**橙黄 `#ffc247` 只用于价格和待付款**——一冷一暖，让"钱"一眼能跳出来。卡片偏方（圆角 14px）、描边极细（1px），靠**发光（glow）而不是重阴影**制造层次；数字、核销码、统计用等宽字体，强化科技感。登录/注册/找回密码/欢迎页是**独立的全屏界面**，不嵌在站内。

### 🔤 排版

*   **字体族**：
    *   正文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
    *   **数字/核销码/统计/标签**：`ui-monospace, "JetBrains Mono", Consolas, monospace`（`--font-mono`）
*   **字号阶梯**：
    *   H1：`30px` / `800` / `1.25`（手机 `24px`）
    *   H2：`21px` / `700` / `1.35`（手机 `18px`）
    *   H3：`16px` / `600` / `1.45`
    *   正文：`15px` / `400` / `1.7`
    *   小字：`13px` / `11px`
*   **字间距**：大标题 `1px`，首页店名 `5px`，欢迎页 `7px`，全大写微标签 `1.4px`

### 📏 空间与形状

*   **基础网格**：`8px`（`--sp-1`~`--sp-7`：4 / 8 / 12 / 16 / 24 / 32 / 48）
*   **容器最大宽度**：`1140px`
*   **圆角（偏方，强化科技感）**：小 `6px` / **按钮与输入框 `10px`** / **卡片 `14px`** / 大区块与登录卡 `18px` / 药丸 `999px`
*   **阴影 / 发光**：
    *   `--shadow-1`: `0 2px 10px rgba(0,0,0,.5)`（面板）
    *   `--shadow-2`: `0 12px 30px rgba(0,0,0,.6)`（登录卡）
    *   **`--glow`: `0 0 0 1px rgba(0,255,157,.35), 0 0 22px rgba(0,255,157,.16)`**（主按钮 hover、输入框聚焦、选中态）

## 3. 组件规范 (Component Guidelines)

*   **按钮 (Button)**
    *   主按钮：荧光绿实底 `#00ff9d`，文字深色 `#04120c`，高 `40px`，圆角 `10px`，内边距 `0 16px`，常态带绿色微光；Hover：转深绿 + `--glow` 发光
    *   次按钮：透明底 + 细描边；Hover：淡绿底 + 描边转绿
    *   强调按钮（付定金 / 注册）：橙黄 `#ffc247` 实底 + 深色字，Hover 提亮 + 暖光
    *   危险按钮（取消 / 拉黑 / 删除）：红色字 + 红描边
    *   按下：`scale(.98)`；禁用：透明度 `.45`
*   **卡片 (Card / Panel)**
    *   背景 `--card`、圆角 `14px`、内边距 `16px`、`1px` 描边 + 阴影1；Hover：上浮 `3px` + 描边转荧光绿 + 阴影2
    *   剧本卡封面固定 `4:3`，有图用图，没图用大字 emoji（封面底带一点绿色渐变）
    *   右上角「收藏心」是方形圆角按钮，收藏后变红
*   **导航 (Navbar)**
    *   高 `58px`，半透明深底 + `blur(10px)` + sticky；底部描边中间一段是**荧光绿渐变亮线**
    *   链接：圆角 `6px`、内边距 `8px 12px`；Hover 淡绿底；**选中态是荧光绿实底 + 深色字**
    *   右侧：🔔 铃铛（未读红点）、☀️/🌙 主题、头像
*   **独立登录界面（`/welcome` `/login` `/register` `/forgot`）**
    *   独立布局 `templates/auth_base.html`：**没有站内导航**，全屏居中，只有顶上的「‹ 门店首页」和主题按钮
    *   背景：固定的网格 + 顶部绿色辉光（`.auth-bg`）
    *   卡片宽 `420px`、圆角 `18px`、阴影2，顶部有一条荧光绿渐变亮线
    *   输入框：「图标 + 占位符」、高 `50px`；「获取验证码」是独立的描边按钮
    *   协议勾选纯 CSS（隐藏 checkbox + 方块圆点 + 勾选发光）
*   **表单**：输入框高 `44px`、圆角 `10px`、底 `#0b1219`；聚焦：描边转绿 + `--glow` 光环
*   **表格**：表头是**全大写弱化小字**（等宽 + 字间距）；行 hover 淡绿底；窄屏横向滚动
*   **徽章 / 药丸**：`badge` 绿底绿边（.new 橙 / .ok 绿 / .warn 黄 / .bad 红）；`pill` 等宽描边款
*   **提示条 (Flash)**：页面顶部整条，圆角 `10px`，默认绿 / 成功绿 / 警告红

## 4. 布局与响应式

*   **栅格系统**：Flex 为主 + `grid auto-fill minmax(240px,1fr)` 自适应卡片网格；两栏 `.two`（`1.7fr / 1fr`）
*   **响应式断点**
    *   移动端 `<= 640px`：卡片两列、两栏改单列、字号下调、登录卡留白收紧、安全区适配
    *   平板端 `641px – 1024px`：两栏改单列
    *   桌面端 `>= 1025px`：完整两栏 + 四列统计
*   **安全区**：支持 `env(safe-area-inset-bottom)` 的设备，页面底部与页脚自动加内边距

## 5. 动效与交互

*   **过渡**：`transition: ... .2s cubic-bezier(.22,.61,.36,1)`（快 `.15s` / 慢 `.35s`）
*   **Hover**：卡片上浮 `3px` + 描边转绿 + 阴影加深；按钮上浮 `1px` + 发光；链接淡绿底
*   **按下**：`translateY(0) scale(.98)`
*   **首页轮播**：3 张、15 秒一轮，纯 CSS 淡入淡出（无 JS）
*   **核销码**：等宽大字 + 绿色文字辉光（`text-shadow`）
*   **无障碍**：`:focus-visible` 有 `2px` 荧光绿描边；`prefers-reduced-motion` 时关闭所有动画

## 6. 给生成模型（AI）的模仿指令（Meta-Prompt）

> "请生成深色科技感的界面：页面底 `#06090d`，卡片 `#0f1620`，描边 `#1b2734`，文字 `#dff7ec` / 说明 `#7d9a92`。主色用高亮荧光绿 `#00ff9d`（hover `#00d97e`），橙黄 `#ffc247` 只用于价格和付款。正文 15px/行高 1.7，H1 30px/800/行高 1.25/字距 1px；数字、核销码、统计、小标签用等宽字体。间距走 8px 网格，容器最宽 1140px；圆角偏方：按钮 10px、卡片 14px。不要用重阴影，用发光：`0 0 0 1px rgba(0,255,157,.35), 0 0 22px rgba(0,255,157,.16)`。所有过渡 `.2s cubic-bezier(.22,.61,.36,1)`。登录/注册做成不带导航的全屏独立界面，卡片 420px 居中，背景是淡网格 + 顶部绿色辉光。断点 640 / 1024，移动端加 `env(safe-area-inset-bottom)`。"

### 附：改观感的三种常见操作

| 想改什么 | 动哪里 |
|---|---|
| 换主色（比如改成青色 / 品红） | 只改 `:root` 里的 `--primary / --primary-600 / --primary-100`，发光 `--glow` 里的 rgba 同步改 |
| 更圆 / 更方 | 改 `--radius`（按钮）和 `--radius-lg`（卡片） |
| 独立登录页 | 改 `templates/auth_base.html` + 样式第 12 段（`.auth-*` 那一组） |
