# 🌐 网站UI设计系统学习文档 - 甜薯剧本杀（Python 版）

> 这份文档描述的是**当前代码的真实样子**，不是设想。改 UI 时先改这里，再改 `tianshu/static/css/style.css`。
> 样式表是唯一的：`tianshu/static/css/style.css`（约 18 KB，分成「设计令牌 / 基础 / 布局 / 组件 / 页面零件 / 浅色主题」六段）。

## 1. 设计概览与风格

*   **关键词**：沉浸 · 暗色 · 暖橙点缀 · 圆润 · 轻量
*   **整体印象**：整体是深夜紫黑的沉浸底色（`#0e0c1a`），紫色 `#8b5cf6` 作为主色负责按钮与选中态，橙色 `#fb923c` 专门留给"钱和行动"（价格、待付定金、注册按钮）—— 一冷一暖，营造"夜里开一局本"的氛围。卡片圆角偏大（18px）、留白充足、描边很淡，靠层级而不是重边框来分区；顶部导航半透明+毛玻璃，滚动时始终吸顶。

### 🎨 颜色

| 用途 | 变量 | 值 |

| 主色浅（链接/弱化） | `--primary-100` | `#c4b5fd` |
| 强调色 | `--accent` | `#fb923c`（价格、待付、行动点） |
| 主背景 | `--bg` | `#0e0c1a` |
| 抬升背景（顶栏/登录卡） | `--bg-elev` | `#161329` |
| 卡片背景 | `--card` | `#1c1834`（hover 时 `#221d3d`） |
| 描边 | `--line` | `#2c2650`（强 `#3b3470`） |

> 浅色主题：`html[data-theme="light"]` 覆盖上面同名变量（背景 `#f6f5fb`、卡片纯白、主色 `#7c3aed`），顶栏 ☀️/🌙 按钮切换，状态记在 cookie 里。

### 🔤 排版

*   **字体族**：系统字体栈 `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`（不引外部字体，打开快）
*   **字号阶梯**：
    *   H1：`32px` / 字重 `800` / 行高 `1.25`（手机 `26px`）
    *   H2：`22px` / 字重 `700` / 行高 `1.35`（手机 `19px`）
    *   H3：`17px` / 字重 `600` / 行高 `1.45`
    *   正文：`15px` / 字重 `400` / 行高 `1.7`
    *   小字：`13px`（说明）/ `11px`（徽章、时间）
*   **字间距**：大标题 `letter-spacing: 1px`，首页店名 `5px`，欢迎页 `7px`

### 📏 空间与形状

*   **基础网格**：`8px`（变量 `--sp-1`~`--sp-7`：4 / 8 / 12 / 16 / 24 / 32 / 48）
*   **容器最大宽度**：`1120px`
*   **圆角**：小 `8px` / **按钮与输入框 `12px`** / **卡片与面板 `18px`** / 登录卡与大区块 `22px` / 药丸 `999px`
*   **阴影**（三档，暗色偏重）：
    *   `--shadow-1`: `0 2px 8px rgba(0,0,0,.28)`（面板常态）
    *   `--shadow-2`: `0 10px 28px rgba(0,0,0,.38)`（卡片 hover）
    *   `--shadow-3`: `0 30px 80px rgba(0,0,0,.45)`（登录卡）

## 3. 组件规范 (Component Guidelines)

*   **按钮 (Button)**
    *   主按钮：紫渐变 `#8b5cf6 → #7c3aed`，无描边，白字，高 `40px`，圆角 `12px`，内边距 `0 16px`；Hover：上浮 `1px` + 亮度 `1.08` + 阴影1；按下：`scale(.98)`
    *   次按钮：透明底 + `1px` 描边 `--line`，文字用默认色；Hover 变亮
    *   强调按钮（付定金 / 注册）：橙渐变 `#fb923c → #f97316`
    *   危险按钮（取消 / 拉黑 / 删）：红色文字 + 红色描边，Hover 淡红底
    *   禁用：透明度 `.5`，不变换
*   **卡片 (Card / Panel)**
    *   背景 `--card`，圆角 `18px`，内边距 `16px`，`1px` 淡描边 + 阴影1（面板）/ hover 时上浮 `3px` + 描边转紫 + 阴影2（剧本卡）
    *   剧本卡封面固定 `4:3`，有图用图（object-fit: cover），没图用大字 emoji
    *   右上角有圆形半透明"收藏心"，收藏后变红
*   **导航 (Navbar)**
    *   高 `58px`，背景 `rgba(22,19,41,.92)` + `backdrop-filter: blur(10px)`，底部 `1px` 描边，sticky 吸顶
    *   链接：圆角 `8px`、内边距 `8px 12px`、间距 `4px`；Hover 浅底，选中态紫底白字；窄屏可横向滚动
    *   右侧：🔔 铃铛（有未读时右上角红点）、☀️/🌙 主题、头像、退出
*   **表单 (Form)**
    *   输入框高 `44px`，圆角 `12px`，深色底 + 淡描边；聚焦：描边转紫 + `3px` 紫色光环
    *   登录/注册卡里的输入框是「图标 + 占位符」样式（无 label），高 `50px`
    *   协议勾选用纯 CSS（隐藏 checkbox + 圆点），不依赖 JS
*   **表格 (Table)**
    *   表头弱化小字 + 字间距；行 hover 浅底；窄屏外层 `.scroll` 横向滚动
*   **徽章 (Badge / Pill)**
    *   `badge` 紫色底（.new 橙 / .ok 绿 / .warn 黄 / .bad 红），圆角 999
    *   `pill` 描边款，用于标签、时间、小状态
*   **提示条 (Flash)**
    *   页面顶部一整条，默认紫底 / 成功绿 / 警告红，圆角 `12px`

## 4. 布局与响应式

*   **栅格系统**：以 Flex 为主 + `grid auto-fill minmax(240px,1fr)` 自适应卡片网格；两栏用 `.two`（`1.7fr / 1fr`）
*   **响应式断点**：
    *   移动端：`<= 640px`（两列卡片、两栏改单列、字号下调、登录卡留白收紧、安全区适配）
    *   平板端：`641px – 1024px`（两栏改单列）
    *   桌面端：`>= 1025px`（完整两栏 + 四列统计）
*   **安全区**：支持 `env(safe-area-inset-bottom)` 的设备自动给页面底部和页脚加内边距

## 5. 动效与交互

*   **过渡动画**：统一 `transition: ... .2s cubic-bezier(.22,.61,.36,1)`（快 `.15s`、慢 `.35s`）
*   **Hover 效果**：卡片上浮 `3px` + 描边转紫 + 阴影加深；按钮上浮 `1px` + 提亮；链接浅底
*   **按下**：`transform: translateY(0) scale(.98)`
*   **首页轮播**：3 张幻灯片，15 秒一轮，纯 CSS `@keyframes` 淡入淡出（无 JS）
*   **欢迎页 logo**：上下浮动 `3.5s` 循环
*   **无障碍**：`:focus-visible` 有 `2px` 紫色描边；`prefers-reduced-motion` 时关闭全部动画

### 附：改 UI 的三种常见操作

| 想改什么 | 动哪里 |
|---|---|
| 换配色（比如改成青色系） | 只改 `:root` 里的 `--primary / --primary-600 / --primary-100 / --accent` |
| 卡片更圆 / 更方 | 改 `--radius-lg`（卡片）和 `--radius`（按钮输入框） |
| 整体更亮 | 改 `--bg / --bg-elev / --card` 三档，或直接在网页上点 ☀️ 看浅色主题 |
