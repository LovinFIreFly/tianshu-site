# 甜薯剧本杀 · UI 设计系统

> 这份文档说明**现在这套界面是按什么方法做出来的**，以及改外观时该动哪里。
> 所有样式集中在一个文件：`tianshu/static/css/style.css`（改外观优先改第 1 节的令牌）。

---

## 一、设计方法：为什么选 Airbnb

看了 10 份设计资料（Airbnb / Apple / Dropbox / Duolingo / GOV.UK / Lando Norris / Nike / Pinterest /
Straits Times / Stripe），最后**以 Airbnb 为主方法**，理由是产品形态对得上：

| 我们的链路 | Airbnb 的链路 |
|---|---|
| 浏览剧本库（卡片网格 + 标签筛选） | 浏览房源（卡片网格 + 筛选） |
| 看剧本详情（人数/时长/角色/评分） | 看房源详情（设施/评分/评价） |
| 选日期 → 选时段 → 选人数 → 下单付定金 | 选日期 → 选人数 → 预订付款 |
| 拼车（凑人成团） | 共享房源 / 体验成团 |

Airbnb 是把「浏览 → 详情 → 选时间 → 下单」这条链路打磨得最成熟的公开参考，而且它的
**暖米底 + 单一珊瑚红**跟之前试过的荧光绿、金灰是两种气质——不容易看出"套模板"。

### 只吸收了这四份的局部零件（都服从 Airbnb 的主形态）

| 来源 | 只借这一件 | 用在哪 |
|---|---|---|
| **GOV.UK** | 表单纪律：标签写在框上方、提示挨着字段、一屏一个任务、正文不小于 16px | 后台 14 个面板（"傻瓜式"的实现依据） |
| **Stripe** | 令牌收敛：间距/字号/阴影只从刻度取；主色面积 <5%；焦点环必须存在 | 整套 CSS 的实现规范 |
| **Duolingo** | "按压感"按钮：同色系深一档的 3px 底边，按下沉 3px | 只给客户端主 CTA（`.btn-cta`） |
| **Pinterest** | 卡片不投重阴影，靠留白与圆角分层 | 剧本卡、拼车卡 |

### 明确没采用的（以及为什么）

- **GOV.UK 的零圆角 + 硬阴影**：那是"公文"气质，跟娱乐场所不符（只借它的表单纪律）
- **Duolingo 的高饱和糖果色与吉祥物**：太儿童向，做门店预订会显得不专业
- **Apple / Nike 的巨型标题（56–186px）与大图 Hero**：那是营销页手法，对工具类界面无益
- **Dropbox / Lando Norris 的滚动叙事、WebGL**：好看但会让下单路径变长
- **Straits Times 的衬线报头**：报纸气质，手机端操作不适用

## 二、设计令牌（改外观只改这一段）

### 色彩

| 用途 | 变量 | 浅色（默认） | 暗色 |
|---|---|---|---|
| 页面底 | `--bg` | `#F7F6F2` 暖米 | `#191817` |
| 次级底 | `--bg-2` | `#F0EEE9` | `#211F1D` |
| 卡片 | `--surface` | `#FFFFFF` | `#232120` |
| 边框 | `--line` / `--line-strong` | `#DFDCD6` / `#C5C1BB` | `#3A3733` / `#4E4A45` |
| 正文 / 说明 / 更弱 | `--text` `--text-2` `--text-3` | `#232221` / `#6E6A66` / `#928D86` | `#F4F2EF` / `#B5AFA8` / `#8B857E` |
| **主色（唯一亮点）** | `--primary` / `-600` / `-100` | `#FF385C` / `#DA1249` / `#FFF5F6` | `#FF5A76` / `#FF3D5F` / `#2A1A1D` |
| 副色（只给"钱/优惠"） | `--accent` | `#C2410C` | `#F5A25E` |
| 状态 | `--ok` `--warn` `--bad` `--info` + 各自的 `-bg` | 绿 / 琥珀 / 砖红 / 蓝 | 提亮版 |

**规矩**：主色只出现在**主按钮、选中态、价格**三处，一屏里彩色面积不超过 5%（Stripe 的纪律）。
浅色是默认；暗色是暖调黑，不是纯黑——由顶栏 🌙 按钮切换，记在 cookie 里。

### 排版

- 字体：系统字体栈（不加载 webfont，快），数字用等宽 `--mono`
- 阶梯：hero 52px（手机 32）· h1 30px · h2 23px · h3 17px · 正文 16px/1.6 · 小字 14 · 极小 12.5
- 大标题 `font-weight:700` + `letter-spacing:-.02em`，行高压到 1.08（Airbnb / Apple 都这么干）
- 中文标题不加字距，只有首页大标题收紧一点点

### 间距 / 形状 / 阴影 / 动效

- 间距：8px 基准 + 4/12/20 半步（`--sp-1`~`--sp-10`），**不许写刻度外的值**
- 圆角：**近零**——控件/卡片 0~2px，只有"洞"（头像/圆点）才用 `--r-round:100%`。
  （2026-09 改过：以前是"胶囊 100px / 卡片 16"——那是典型 AI 味：统一大圆角不加区分）
- 阴影：软阴影 3 档只给**浮层**（弹窗/下拉）；要"突出可按"用**硬投影** `--sh-hard:3px 3px 0`（不模糊）；
  按下时位移 3px 把投影吃掉 = 真按压感。卡片默认**不投**软阴影，靠细线分层
- 动效：175 / 220 / 320ms，统一 `cubic-bezier(.2,0,0,1)`；`prefers-reduced-motion` 时全部关掉

## 三、组件规范

| 组件 | 规则 |
|---|---|
| **按钮** `.btn` | **直角 + 1.5px 墨色描边**。三种按钮三种反馈：主按钮朱红 + **硬投影**（hover 抬起、按下吃掉投影）；次要按钮 hover **反色**（墨底纸字，不是"变浅"）；危险按钮 hover 实心红。禁用 = 虚线框 + 降饱和 |
| **主 CTA** `.btn-cta` | 高 52px + 3px 同色系底边，按下沉 3px。**一屏只给一个** |
| **表单** `.field` | 标签在上（13px 灰）、框 46px 高、聚焦时珊瑚描边 + 3px 光环；提示写在字段下方 |
| **卡片** `.card` / `.panel` | 白底 + 1px 暖边框 + 1 档阴影；**不投重阴影**；hover 才浮起 |
| **胶囊** `.pill` / `.chip` | 34px 高、100px 圆角；选中态是"深色底白字"（不是变色） |
| **剧本卡** `.juben` | 上图（4:3）+ 下文的房源卡形态；价格珊瑚粗体；CTA 是浅珊瑚药丸。**第一部是头条**：`.grid > .juben:first-child` 横跨两列、封面改 16:9、标题 26px（打破均等栅格） |
| **状态**（空/加载/错/禁用） | `.empty` 虚线框 + 一句人话；`.skel` 骨架微光；`.field.err` 加粗红框；`input:disabled` 虚线 + 降饱和。**四态必须都做**，只画默认态就是 AI 味 |
| **后台侧栏** `.adm-side .navi` | 42px 圆角行；选中态浅珊瑚底 + 珊瑚字；手机端变顶部横滑胶囊条 |
| **弹窗** `.mask` / `.modal` | 遮罩 78% 深 + 6px 模糊；`.modal.mid` 580px，`.small` 440px。**弹窗内部是一整块纸面**：分区只用细线（`.modal .adm-panel` 去掉底色/边框），套小白框会显得"有东西被挡在后面" |
| **角色多选胶囊** `.chip-check` | 后台用户面板的「② 角色 / 权限」：复选框做成勾上就反色的胶囊（`.on` / `.off` 由 JS 同步，别只靠 `:has()`）。角色是**可以多选**的：DM + 管理员能同时挂 |
| **手机底部导航** `.mobtab` | 只在 ≤744px 出现的固定底栏：首页 / 剧本库 / 拼车 / 我的，桌面端 `display:none`。`base.html` 里渲染（`comm.html` 那个 `.tabbar` 是后台式文字横条，不是这个）。加了它之后 `.wrap` 底部自动留 72px，别把内容压在下面 |
| **欢迎页** `.welcome-card` | 进站第一屏（`welcome.html`）：88px 深色方块 logo + 56px 标题 + 一句 slogan + 登录/注册两颗按钮。`.auth-stage` 已居中，别再加外边距 |
| **折叠** `details.spoiler` | 虚线分隔 + ▸ 旋转；进阶项默认收起（"傻瓜式"的关键） |
| **提示** `.flash` | 页顶一条，按语义上色（ok 绿 / warn 红 / 默认蓝） |

## 四、改法速查

| 想改什么 | 怎么做 |
|---|---|
| 换主色（比如改成青色） | 改 `:root` 的 `--primary` / `--primary-600` / `--primary-100` / `--primary-rgb` 四个值（`-rgb` 是给半透明用的，必须同步） |
| **弹窗位置错乱 / 像被挡住** | 先查祖先有没有 `transform`（动画、hover 位移、`translateY`）—— 有的话里面 `position:fixed` 的弹窗会改成"相对那个祖先"定位。面板入场动画（`.tabpane.on`）只准动 `opacity`，这条踩过一次 |
| **深浅色切换后某块变浅 / 字看不见** | 深色模式下 `--paper` 与 `--ink` 是**对调**的。凡是「整幅墨色」的块（首屏 `.hero`、`.band.ink`、我的资料卡 `.profile`）都要用不跟主题翻的 `--stage` / `--stage-ink` / `--stage-hair`；里面的说明文字本来就是写死的浅色，一翻就成"浅底浅字" |
| 改欢迎页文案 | `templates/welcome.html`（进站第一屏）。要不要给某人看欢迎页的开关在 `views/public.py` 的 `home()`：游客 + 没逛过 → 欢迎页 |
| 卡片更圆 / 更方 | 改 `--r-lg`（卡片）、`--r`（输入框）、`--r-pill`（控件） |
| 页面更"松" / 更"紧" | 改 `--sp-*` 刻度，或 `.wrap` 的 padding |
| 后台默认展开某个面板 | `templates/admin/index.html` 里把 `'on' if loop.first` 挪到那一项 |
| 加一个后台功能 | ① `views/admin.py` 写视图函数 ② 文件末尾 `_TAB_FUNCS` 加一行 ③ `templates/admin/index.html` 的 `NAVI` 加一行 |
| 暗色下某处不好看 | 在 `html[data-theme="dark"]` 里覆盖那个变量，**别在组件里写死颜色** |

## 六、去「AI 味」：2026-09 重构的取舍

AI 味的本质不是丑，是**安全、平均、没有主观取舍**。所以这一版不是"换个更好看的模板"，
而是**每一处都明确选择放弃什么**。出处都来自《30 站 UI 设计知识文档》：

| AI 通病 | 我们的取舍 | 学的是谁（文档编号） |
|---|---|---|
| 所有元素统一大圆角 | **近零圆角**（0/2px），只有"洞"才圆 | 19 We are Büro（直角、拒绝圆角讨好） |
| 万能淡软阴影 | 软阴影只给浮层；强调改用**不模糊的硬投影** | 27 Mailchimp（硬投影 CTA） |
| 白底 + 数码塑料感 | 全站盖一层 **opacity .035 噪点**，像真的纸 | 11 Symphony of Vines（噪点 .015） |
| 所有 hover 都是"上浮 + 变浅" | 主按钮按下**吃掉投影**；次要按钮 hover **反色** | 19 / 27 |
| 3 列 4 列绝对均等 | **头条横跨两列 + 封面改 16:9**，有主有次 | 19（排版即主角） |
| 只画默认态 | 补齐 **空 / 加载 / 错误 / 禁用** 四态 | —（人工 UI 的底线） |
| 渐变到处点缀 | 渐变 0 处，靠细线（`--rule`）分层 | 31 The Guardian（排版即品牌） |

**以后加东西的三条硬规矩：**

1. 想加圆角 → 先问是不是"洞"（头像/圆点），不是就别圆；
2. 想加阴影 → 先问是不是浮层，不是就用硬投影，或者干脆不加；
3. 想加装饰 → 先问它解释不解释业务（场次号、余位、朱红印记可以；光晕、粒子、漂浮几何一律不行）。

## 七、外观款式（skin）：后台统一切换，全站生效

一套 skin = **叠在主样式 `style.css` 之上的一层覆盖**（`static/css/skin-<key>.css`）：
只换设计语言，**不动结构、不动功能**，所以换款式不会把业务换坏。

- 管理员在**「后台 → 门店设置 → 外观款式」**里选 → **全站统一**（手机端 + 电脑端一起变），
  客人不需要也不允许自己选；
- 管理员想先看效果：任意页面网址后加 `?skin=<key>`（只有管理员生效）——**先预览、再决定**；
- 可选值写在 `business.SKINS`（**白名单**，key 必须等于 CSS 文件名）；
  这个值会拼进静态文件路径，所以后台保存时只在白名单内才收，拿不到就退回默认。

| key | 款式 | 语言 |
|---|---|---|
| `playbill` | 戏单 · 铅字印刷（**默认**） | 报头居中 / 双线 / 编号条目 / 直角墨框 |
| `noir` | 墨 · 暗色影院 | 暗色**灰阶分层**（不用阴影）/ 朱红点缀 |
| `riso` | Riso 三色套印 | 三原油墨 + 巨型字 + 套印错位 |
| `swiss` | 瑞士网格 | 纯白无衬线 / 细线 / 高信息密度 |
| `monolith` | 石碑 · 灰岩 | 灰底 / **单点正红** / 巨型字，**去掉所有卡片框** |

**新增一款式**：写一份 `static/css/skin-<key>.css`（只覆盖令牌 + 关键组件，
别复制整份主样式），再往 `business.SKINS` 加一行即可 —— 后台下拉会自动多出一项。
