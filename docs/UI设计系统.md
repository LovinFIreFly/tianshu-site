# 甜薯剧本杀 · UI 设计系统（午夜影院 Midnight Cinema）

> 这份文档描述的是**当前代码的真实样子**，改 UI 前先看这里，动手只改一个文件：
> `tianshu/static/css/style.css`（第 1 节就是全部设计令牌，改配色只改那一块）
> 页面结构：`tianshu/templates/`，一个页面一个文件；后台/DM/我的 都是「一个网址 + 标签页」。

## 1. 设计概览

*   **关键词**：午夜影院 · 低对比 · 单一暖色点缀 · 克制
*   **整体印象**：底是中性冷灰黑（不偏绿、不偏紫），靠**描边**而不是阴影分层（参考 Vercel / Tabler 的暗色做法）；整套界面只有**一处亮色**——暖金 `#e0b264`，用在主按钮、选中态、价格和焦点环上；其余全是灰阶层级。副色靛蓝 `#7c9bf0` 只在信息类地方出现（拼车标记、次要按钮），一屏里通常不超过两处彩色。
*   **前两版踩过的坑**（留个记录）：① 荧光绿那版满屏发光，看着像模板；② 金绿混搭那版只换了主色变量，网格线和文字还带薄荷绿调，所以"看着一般"——**配色要换就整套一起换**，令牌必须自洽。

## 2. 设计令牌

### 🎨 颜色

| 用途 | 变量 | 值 |
|---|---|---|
| 主色（主按钮/选中/价格/焦点） | `--primary` | `#e0b264` |
| 主色 hover / 浅色文字 | `--primary-600` / `--primary-100` | `#c9994a` / `#f0d9ab` |
| 主色透明底（徽章、Hover 背景） | `--primary-rgb` | `224,178,100`（配 `rgba(var(--primary-rgb),.12)` 用） |
| 副色（信息类点缀） | `--info` / `--info-100` | `#7c9bf0` / `#b3c6f8` |
| 页面底 / 顶栏 / 卡片 / 卡片 Hover | `--bg` `--bg-elev` `--card` `--card-hover` | `#0b0d11` / `#11141a` / `#151920` / `#1a1f28` |
| 描边 / 强描边 | `--line` / `--line-strong` | `#252b36` / `#333b49` |
| 文字：标题 / 说明 / 更弱 | `--text` `--text-2` `--text-3` | `#e9ecf2` / `#98a1b0` / `#6a7381` |
| 状态：成功 / 警告 / 危险 | `--ok` `--warn` `--danger` | `#5cc98d` / `#e5a13a` / `#e5657a` |

> 浅色主题：`html[data-theme="light"]` 覆盖同名变量（底 `#f6f7f9`、卡片纯白、主色转深金 `#b8860b`），顶栏 ☀️/🌙 切换，状态存 cookie。

### 🔤 排版

*   **字体**：正文用系统字体栈；**数字、核销码、统计、价格**用等宽字体（`--font-mono`），一眼能对数字
*   **字号**：H1 `28/700/1.3`（手机 23）· H2 `20/650/1.4` · H3 `16/600` · 正文 `15/1.7` · 小字 `13` / `11.5`
*   **字间距**：正文 0（中文不要加）；只有首页店名和欢迎页加 5~6px

### 📏 空间与形状

*   **间距**：8px 网格（`--sp-1`~`--sp-7`：4/8/12/16/24/32/48）
*   **容器**：`1140px`
*   **圆角**：小元素 8 · **按钮输入框 10** · **卡片 14** · 登录卡 18 · 药丸 999
*   **阴影**：深色下阴影不可靠，主要靠描边。只保留两档：`--shadow-1` 极轻、`--shadow-2` 给浮层
*   **焦点环**：`--ring: 0 0 0 3px rgba(224,178,100,.22)`

## 3. 组件规范

*   **按钮**：高 38px（小号 32）、圆角 10、内边距 0 16。
    *   主按钮：暖金实底 + 深色字（`#1a1408`）；次按钮：透明底 + 描边；危险按钮：红字红描边；信息按钮（`btn-accent`）靛蓝淡底。
    *   交互：hover 换底色，按下 `scale(.985)`，禁用 45% 透明。**不做发光、不做上浮**。
*   **卡片**：背景 `--card`、圆角 14、内边距 16、1px 描边。hover 只换描边色和背景（手机上不生效 hover）。
*   **标签栏（重要）**：`.tabbar` —— 后台、DM 工作台、「我的」都用它。样式是**下划线式**（当前项金黄下划线），横向可滚动，永远只在**一个网址**里切换（`/admin?tab=xxx`）。
*   **表单**：输入框高 42、圆角 10、底色 `--bg-elev`；聚焦换描边 + 焦点环。
    *   **自动填充**：`html` 声明了 `color-scheme: dark`，再加 `input:-webkit-autofill` 的内阴影兜底。**输入框自身绝不能再写 `box-shadow: ... !important`**，否则会把自动填充的压底覆盖掉，输入框会在失焦后变成白块（踩过两次）。
    *   **文件上传**：`input[type=file]` 是虚线框 + `::file-selector-button` 金色按钮，原生那行"选择文件"已经被皮肤盖住。
*   **表格**：表头是全大写弱化小字；行 hover 只提亮 2.5%。
*   **徽章/药丸**：`badge` 有 default/new/ok/warn/bad 五态，全部 12% 透明底 + 24% 描边（不用实底色）。

## 4. 布局与响应式

*   **栅格**：Flex 为主 + `grid auto-fill minmax(240px,1fr)`；两栏 `.two`（1.7fr / 1fr）
*   **断点**：手机 `≤640`（卡片两列、两栏改单列、字号下调、安全区）· 平板 `641–1024`（两栏改单列）· 桌面 `≥1025`
*   **安全区**：`@supports(padding-bottom: env(safe-area-inset-bottom))` 给页面底部和页脚补偿

## 5. 动效与性能

*   **过渡**：`.18s cubic-bezier(.22,.61,.36,1)`（快 .12 / 慢 .3）；只过渡颜色、背景、描边、transform
*   **首页轮播**：3 张、15 秒一轮，纯 CSS 关键帧
*   **性能红线（别踩）**：
    *   不用 `background-attachment: fixed` 画背景（滚动时每帧重绘整屏）→ 用固定定位的 `body::before` 伪元素代替
    *   顶栏不要用 `backdrop-filter: blur`（低端机滚动掉帧）→ 用不透明底色
    *   列表页首屏别一次渲染几百条（后台表格已按需分段）
*   **无障碍**：`:focus-visible` 有 2px 金描边；`prefers-reduced-motion` 时关闭全部动画

## 6. 给 AI 的模仿指令（Meta-Prompt）

> "生成一个暗色影院风的界面：底 `#0b0d11`，顶栏 `#11141a`，卡片 `#151920`，描边 `#252b36`，文字 `#e9ecf2` / 说明 `#98a1b0`。主色只用暖金 `#e0b264`（hover `#c9994a`），只给主按钮、选中态、价格和焦点环；副色靛蓝 `#7c9bf0` 仅用于信息标记。正文 15px/行高 1.7，H1 28px/700，数字用等宽字体。间距走 8px 网格，容器 1140px，按钮圆角 10、卡片圆角 14。不要发光、不要渐变按钮、不要重阴影——靠 1px 描边分层。列表型管理页面用 `.tabbar` 下划线标签栏，全部功能在一个网址里用 `?tab=` 切换，不要一个功能一个页面。过渡统一 `.18s cubic-bezier(.22,.61,.36,1)`；禁用 `background-attachment:fixed` 和 `backdrop-filter`。"

### 附：三个高频改法

| 想改什么 | 怎么做 |
|---|---|
| 换主色（比如改成青色） | 改 `:root` 的 `--primary / --primary-600 / --primary-100 / --primary-rgb` 四个值（`--primary-rgb` 是给半透明用的，必须同步） |
| 卡片更圆 / 更方 | 改 `--radius-lg`（卡片）或 `--radius`（按钮输入框） |
| 新增一个后台功能 | ① 写个视图函数 ② 在 `views/admin.py` 末尾 `_TAB_FUNCS` 加一行 ③ 在 `templates/admin/_nav.html` 加个标签 |
