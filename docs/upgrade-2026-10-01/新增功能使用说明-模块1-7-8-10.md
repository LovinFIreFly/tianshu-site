# 新增功能使用说明（模块 1 / 7 / 8 / 10 · 2026-10-01）

> 本文档只描述本轮真实落地的功能与使用方法；需要外部资源才能开通的功能（微信订阅消息、短信、真实开票服务）不在其中，见「外部依赖预留」一节。

## 一、玩家端（手机 /m 与桌面通用）

### 1. 拼车与组局
- **风格标签**：我的页 → 编辑资料 → 勾选你的剧本风格（菠萝头/水龙头/推理机/戏精/全类型，可多选）→ 保存。之后你上车的车队，成员列表会显示各人标签；系统会提示「有和你口味相近的玩家在车上」。
- **多维筛选**：拼车大厅顶部新增筛选条——按剧本名搜索、按人数、按时段（上午/下午/晚上）、按难度（1-5）过滤车队；桌面与手机均可。
- **席位倒计时**：开团时默认 24 小时后截止（店主可在后台改默认小时数）。车队卡片显示「剩 X 小时 · 还差 Y 人」；超过截止时间显示「已截止」，车主标记补满后显示「补满发车」。
- **超时补车**：车主（或店员）在车队详情页可点「提前截止」「标记补满」——截止后该车不再收人，补满后视为满员发车，系统会通知车上与候补的人。
- **车主奖励**：你开团并完成核销的车达到阈值（默认 5 次，店主可配），系统自动发一张券（默认 10 元，可配）到你的账号，并站内通知。
- **演员招募帖**：社区发帖时可选「缺位招募」，填缺几人 / 缺什么位（推理位/情感位…）/ 哪本本；帖子显示「缺 X 人 · 话题 · 职位」徽章，可按「缺位招募」和话题（情感/硬核/恐怖/欢乐）筛选。
- **一键分享**：剧本详情与车队详情页有分享按钮（手机走系统分享，桌面复制链接与文案）：『甜薯剧本杀｜《title》day time 还差 need 人，一起？』。
- **热玩/新本**：首页新增「热玩本 / 新本首车」两个聚合区，快速浏览高热度与刚上架的本。

### 2. 内容与资料
- **演后复盘**：DM/店主登录后打开剧本详情可看到「演后复盘」折叠区（店主后台维护，支持多段落文本）；普通玩家看不到（防止剧透）。
- **角色卡**：剧本详情页展示角色列表（角色名 + 一句话人设 + 海报位），手机在剧本详情弹层里可看。
- **演绎视频**：剧本详情页若有「演绎视频」按钮（店主后台配置的外链），点击即可观看。
- **话术库**（DM/店主）：DM 工作台与后台新增「话术库」面板，分类（开场白/过渡/结尾/其他）维护带本话术模板，开本前随时取用。

### 3. 消息与触达
- **开本提醒**：打开通知中心（桌面右上角铃铛 / 手机我的页）会自动生成开场提醒——开场前 1 小时「稍后 X 点开《…》」、开场前 1 天「明天开场」，不重复推送。
- **退款通知**：退款发起时通知文案明确为「已发起原路退回，1-3 工作日到账」。
- **客服入口**：我的页「客服」块：一键复制客服微信 + 直达常见问题 + 给店家留言。
- **常见问题（FAQ）**：独立 FAQ 页（桌面页脚入口）与手机 FAQ 弹层，含六条高频问答：定金能退吗 / 能迟到吗 / 几人开 / 怎么拼车 / 核销码怎么用 / 改期规则。
- **电子发票**：我的订单中已支付订单旁有「申请发票」→ 填抬头/税号/邮箱提交；店主后台「开票请求」列表人工标记已开，标记后你会收到「发票已开好」通知（真实纸质/电子票面由店家线下提供）。
- **消费后自动邀评**：核销成功后通知中心自动生成「写个短评吧」，点进去直接评价。

### 4. 技术基建
- **主题三态**：桌面右上主题按钮循环切换 日 / 夜 / 跟随系统；手机顶部主题按钮同样三态，选择「跟随系统」后随设备深色模式实时切换。
- **收藏分组**：我的页收藏变为三组：想玩 / 已玩 / 避雷；收藏/取消时可切换分组（手机长按收藏项或详情内选择）。
- **分享卡片**：把本站任意页面分享到微信/朋友圈时，会带标题、简介与封面图（Open Graph）。
- **离线可用**：访问过的静态资源在断网时仍可打开外壳页面（PWA v4 缓存升级）。
- **空态引导**：所有空列表都带行动按钮（去剧本库 / 去发帖 / 去拼车等）。

## 二、店主 / DM 端（管理后台 / DM 工作台）

| 新能力 | 入口 | 操作 |
|---|---|---|
| 拼车参数配置 | 后台 → 设置 | 车队截止默认小时数 `carDeadlineHours`、车主奖励阈值 `carRewardThreshold`、奖励券面额 `carRewardValue`（非法输入自动回退默认 24/5/10） |
| 车队截止/补满 | 后台 → 预约 | 车主车队列表每行「提前截止」「标记补满」按钮 |
| 剧本复盘/视频/角色人设 | 后台 → 剧本 → 编辑 | 复盘文本域 `reviewDoc`、演绎视频 URL `videoUrl`、每个角色一行人设 `role_line_<序号>` |
| 话术库 | 后台 → 话术库（DM 工作台同入口） | 分类维护开场白/过渡/结尾/其他；DM 与店主均可增删 |
| 开票请求 | 后台 → 开票 | 玩家申请发票列表，核对后「标记已开」 |
| 访问统计 | 后台 → 访问统计 | 今日 PV/UV、近 7 日趋势、热门页面 Top10（按天 + IP 哈希去重，不记录真实 IP） |

## 三、外部依赖预留（需你提供资源后才会真正启用）

| 项 | 现状 | 启用条件 |
|---|---|---|
| 微信订阅消息（开本提醒等） | 设置项占位（`wechatSub`），后台界面只读说明；当前站内通知 + 邮件兜底 | 注册微信公众平台并开通模板消息权限 |
| 短信网关（预约/提醒短信） | 设置项占位（`smsGateway`），只读说明；当前邮件 + 站内兜底 | 购买短信服务商通道 |
| 电子发票真实开票 | 现为「后台人工标记已开」流程 | 接入税控/开票服务商 |
| 分享小程序码 | 未接入（分享用页面 URL） | 注册小程序后替换分享文案 |
